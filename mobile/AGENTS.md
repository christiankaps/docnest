# Mobile subproject

Read [PROJECT.md](PROJECT.md) for this project's state and accepted concept decisions.

Prefix commit messages for changes in this subproject with `[mobile]`.

Write implementation plans as checkbox lists. Check items only after implementation and required verification. Finalize each increment by completing all its items and recording the outcome before starting the next increment.

Record accepted product decisions in PROJECT.md and implementation progress in PLAN.md; keep unresolved choices as TBD. Resolve small reversible details independently and ask about consequential product decisions before implementation. Use `make help` for commands and `make verify` before integration. Edit project.yml and regenerate rather than editing the generated Xcode project.

Keep this folder self-contained: no dependencies on or references to files outside it. Copy reused assets into this project. Preserve unrelated work, keep changes small, and verify before claiming success. Establish local build and verification commands when implementation begins.
